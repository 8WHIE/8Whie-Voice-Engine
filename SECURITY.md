## 1. Reporting Security Vulnerabilities
If you discover a security vulnerability or exploit in 8WHIE VoiceForge (including potential watermark circumvention, input injection, or authentication bypass), please report it directly to:

- **Security Team**: `security@8whie.org`
- **Founder**: Aryan Thakur (`aryan@8whie.org`)

Please do not open public GitHub issues for security vulnerabilities.

---

## 2. Deepfake & Abuse Reporting
If you identify synthetic audio generated by 8WHIE VoiceForge being used for fraud, unauthorized impersonation, or harassment:
1. Provide the audio file or recording URL.
2. Our forensics team will analyze the 19.5 kHz pilot watermark and trace the consent signature hash.
3. Identified abusive accounts will be blacklisted and reported to relevant authorities.
