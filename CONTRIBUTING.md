Thank you for your interest in contributing to **8WHIE VoiceForge**!

## Originality & Legal Rules for Contributors
Before submitting any pull request or contribution:
1. **No Copied Code**: All contributions must be original work. Do not copy code from OmniVoice or any other existing repository.
2. **License Compatibility**: Any introduced third-party dependency must use a permissive open-source license (MIT, Apache-2.0, BSD, ISC) and must be documented.
3. **No Unlicensed Datasets**: Do not submit proprietary voice recordings, copyrighted audio clips, or non-commercial datasets.
4. **Attribution**: Contributors acknowledge that project branding and core ownership belong to 8WHIE and Aryan Thakur.

## Development Workflow
1. Fork the `8whie/voiceforge` repository.
2. Create a feature branch: `git checkout -b feature/your-feature`.
3. Test frontend: `npm run lint` and `npm run build`.
4. Test backend: `cd backend && pytest`.
5. Submit a pull request with detailed rationale.
